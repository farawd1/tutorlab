# Tutorlab

Платформа для преподавателей и репетиторов по математике, физике и информатике. Преподаватель создаёт собственный курс, приглашает учеников кодом, загружает лекции и видео, составляет задачи и экзамены, проверяет работы. Готовых курсов в продукте нет.

## Возможности

- Регистрация и вход преподавателя и ученика, смена пароля, серверные сессии и разграничение доступа по курсам.
- Лекции с текстом, PDF/изображением/TXT до 10 MB или видео MP4/WebM до 90 MB. Файлы лежат в R2, метаданные — в D1. Видео открывается только участникам курса.
- Числовые, письменные и программные задачи. Числа проверяются автоматически; письменные решения получают ручной балл или предложение DeepSeek; код проверяется Judge0 по открытым и скрытым тестам.
- Экзамен с одной попыткой, серверным сроком, защитой от повторной сдачи задачи и журналом событий наблюдения. Камера включается учеником отдельно; кадры обрабатываются на устройстве и не сохраняются. Сигналы не влияют на оценку автоматически.
- Итоговый балл и комментарий публикует преподаватель.

## Локальный запуск

Нужен Node.js 24 и npm. В папке `tutorlab`:

```powershell
npm ci
node scripts/setup-vision.mjs
node scripts/run-framework.mjs build
```

Для новой локальной базы примените миграции по порядку:

```powershell
node node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_complex_mimic.sql
node node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_even_caretaker.sql
node node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_fixed_mantis.sql
```

Эти команды нужны только для пустой базы; повторное применение не требуется. Затем запустите `..\START.ps1` или `node scripts/run-framework.mjs dev --hostname 127.0.0.1`. Локальные данные сохраняются в `.wrangler/state`.

## DeepSeek и Judge0

Скопируйте `.dev.vars.example` в `.dev.vars` и добавьте свой ключ DeepSeek:

```dotenv
AI_API_KEY=...
AI_BASE_URL=https://api.deepseek.com
AI_MODEL=deepseek-chat
JUDGE0_URL=https://ce.judge0.com
```

Ключ хранится только на сервере. В DeepSeek передаются условие, эталон, критерии и текст решения; ответ модели — предложение преподавателю, а не окончательная оценка. Публичный Judge0 CE может работать без ключа, но для стабильной эксплуатации нужен собственный или коммерческий endpoint. Исходный код ученика отправляется на выбранный Judge0.

## Проверки

```powershell
node node_modules/typescript/bin/tsc --noEmit
node --test tests/grading.test.mjs
node scripts/run-framework.mjs build
# при запущенном локальном Worker:
node scripts/product-check.mjs
```

`product-check.mjs` создаёт временные аккаунты и курс в локальной базе, проверяет доступ, экзамен, оценку и видео. Никаких платных AI-запросов он не делает.

## Границы текущей версии

Для сброса забытого пароля пока нужен почтовый сервис; в интерфейсе есть смена пароля для вошедшего пользователя. Видео ограничено 90 MB на файл. Проверка MIME опирается на тип, переданный браузером; для приёма произвольных публичных загрузок понадобятся проверка содержимого и антивирус. У экзамена одна попытка, а прокторинг даёт лишь сигналы для ручного разбора. Видео с камеры на сервер не отправляется. Большие потоки и организационные роли потребуют отдельной настройки перед широким запуском.
